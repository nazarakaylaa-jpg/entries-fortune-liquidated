# Fortune Cookie for the Liquidated Trader

Entry for the make.fun competition
`u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c`.

`main.ts` (Node 22, TypeScript, no network) writes a single fortune cookie
line — at most 20 words of plain text — for a crypto trader who has just
been liquidated, to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

## The fortune

> You will soon recover everything you lost, the stars insist. The stars have never held a leveraged long.
